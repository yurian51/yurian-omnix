# YURIAN AI OS

## Vision
YURIAN AI OS is an AI-native operating system for individuals, professionals, developers, teams, and businesses to manage knowledge, projects, documents, tasks, workflows, integrations, and business operations through intelligent agents.

## Core loop
Understand → Plan → Reason → Use Tools → Ask Approval When Needed → Execute → Verify → Learn → Remember.

## Architecture
- Next.js + TypeScript frontend
- NestJS + TypeScript backend
- PostgreSQL + Prisma
- Redis + BullMQ
- WebSockets and REST APIs
- Provider abstraction for AI models
- Structured tool calling
- RBAC and tenant isolation
- Auditability and verification

## Principles
Security first, provider agnostic, modular, observable, testable, and production-oriented.
